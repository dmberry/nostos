# Provenance — "Great Scientists" web feature images

All images sourced from Wikimedia Commons under Public Domain, CC0, or a
CC-BY / CC-BY-SA licence (as permitted). Each file was fetched at 600px wide
(server-scaled where the source was larger; native width kept, never upscaled,
where the source was smaller), re-encoded as baseline JPEG, and checked into the
20–140KB band. Two files are below 600px because their Commons source is smaller
(noted below).

Source file pages live at `https://commons.wikimedia.org/wiki/File:<source file>`.
