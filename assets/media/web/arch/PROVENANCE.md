# Architects & Architecture — image provenance

All images sourced from Wikimedia Commons, licensed Public Domain / CC0 / CC-BY /
CC-BY-SA only. Each downloaded at 600px wide (native aspect preserved), re-encoded
as JPEG within a 20–140KB budget. No file was upscaled. Retrieved 2026-08-19.

Where a photo depicts a modern building, the building's own design may still be in
copyright; these files rely on the photograph's free licence plus freedom-of-panorama
(FoP) in the country of the building (France, UK, Germany, Spain, Brazil, Mexico,
Japan, and the US all permit FoP for buildings). Only files whose Commons licence is
clearly PD/CC were taken.

## Notes
- Le Corbusier: the CC-BY-SA 3.0 candidate was only 297px wide; replaced with the
  CC0 Anefo 1964 portrait (native 1946px), giving a full 600px image.
- Zaha Hadid and Bauhaus Dessau: the top search hits (Dmitry Ternovoy's Hadid photo;
  A.Savin's Dessau photo) are licensed FAL (Free Art License), which is outside the
  permitted set, so CC-licensed alternatives were used instead.
- Eiffel Tower: a daytime image was chosen deliberately; the tower's night lighting
  is separately copyrighted, the structure itself is public domain.
- Nothing was skipped: all 19 requested items had a valid free source.
