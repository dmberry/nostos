## Notes

- **Skipped: Akira Toriyama (toriyama-01)** — no free-licensed photograph of Toriyama exists on Wikimedia Commons (searches returned only unrelated place names and his PD signature). Skipped per instruction.
- **miyazaki-01** — the only free solo portraits of Hayao Miyazaki on Commons are low-resolution; the largest genuine one (342px wide) was used at native width without upscaling, so this file is narrower than 600px.
- **tezuka-01** — source is 595px wide; used at native width (not upscaled).
- **mccay-01** — the photograph itself is public domain (1906); the specific high-resolution file carries a CC BY-SA 4.0 tag from the digitising institution (Ohio State University).
- **little-nemo-01** — the 1907-09-29 page was tried first but its aged-newsprint scan would not compress under 143KB at 600px without severe quality loss; the cleaner 1905-10-22 scan was substituted.
