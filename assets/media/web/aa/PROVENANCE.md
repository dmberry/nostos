## Notes

- `nkrumah-01.jpg`: Wikidata's designated image is a Soviet postage stamp; replaced with the photographic White House portrait by Abbie Rowe (US federal work, public domain) for a better character portrait. Source was 320px wide and upscaled to 600px, so it is slightly softer than the others.
- `biko-01.jpg`: Commons hosts this as public domain (credited to Cape Argus, via a memorial flyer scan). Retained on the strength of the Commons licence tag; the PD status of this 1970s South African press image is the one entry worth a second look if strict provenance matters.
- Several sources were PNG/WebP (fanon, cabral, aidoo, nishida) and were converted to JPEG.
